# pokéOS 
<img width="auro" height="300" alt="image" src="https://github.com/user-attachments/assets/0417697c-575a-4d76-8c48-396f7e3a3df8" />

a pokémon themed web desktop OS built with vanilla html, css, and js. made as part of hack club's webOS jam.

**[live demo](https://sahilchess.github.io/Pokemon-Web-OS/)**

---

## features

- draggable, resizable windows
- window z-index management so clicking a window brings it to the front
- top bar with live clock and pokémon theme song button
- desktop icons that highlight when their window is open
- pokéRecords app with a sidebar + content panel for tracking your pokémon team and moves
- pokémon themed fonts, colors, and UI

## structure

```
Pokemon-Web-OS/
├── assets/
│   ├── bg-images/      # cycling background images (implemmetation removed)
│   └── ...             # icons, logo, audio
├── index.html
├── style.css
└── script.js
```

## running locally

just open `index.html` in a browser, no build step needed.

## built with

- html, css, js (no frameworks)
- [concert one](https://fonts.google.com/specimen/Concert+One), [londrina solid](https://fonts.google.com/specimen/Londrina+Solid), [varela round](https://fonts.google.com/specimen/Varela+Round) via google fonts
- drag and drop logic adapted from w3schools
